# Portfólio Profissional

Esse projeto tem como objetivo apresentar o meu portfólio profissional, através de uma página web dinâmica e responsiva.

### Tecnologias previstas
#### Front-end:
- React Native
- Tailwind

#### Back-end:
- Spring Boot (Java)

#### Banco de dados:
- PostgreSQL
